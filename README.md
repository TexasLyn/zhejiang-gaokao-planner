# 浙志愿 · 浙江高考志愿工作台

面向浙江省高考考生的本地志愿管理工具：从选科、查数据、排方案，到用官方志愿表 PDF 模拟录取结果，全程在浏览器本地完成，无需联网与部署。

> 项目原名为「高考志愿管理工具（全能版）」，现已按需求重命名并全面重构。

## 快速开始

直接用 Chrome / Edge 打开 `index.html` 即可，无需安装任何环境。首次打开会进入引导，依次设置选考科目（7 选 3）、高考总分与全省位次。

所有数据与设置保存在浏览器 `localStorage` 中，不会上传。

### 院校属性胶囊

查询结果与志愿表中的院校名旁会显示院校属性标签（985 / 211 / 双一流 / 2011计划 / 保研 / 卓越工程师 / 省重点建设 / 公办 / 民办 等），数据来自官方投档线文件中的「院校水平」字段与校名括号标注。点击院校名可打开院校卡片：省份、城市、办学性质、2026 专业数、计划总数、投档分/位次区间、招生章程链接与各专业投档明细——这是未来「院校介绍」功能的数据基础。

院校卡片还整合了多份权威数据：软科 2026 中国大学排名、全国高校院校资料（花称、主管部门、建校时间、招生电话、地址、学科评估、推免率）、国家电网 2026 第一批招聘院校名单（录用人数）、中外合作办学机构与项目名单。

### 梯度体检

志愿表工具栏的「体检」会生成方案健康分与逐项报告：冲稳保比例（建议约 2:5:3）、志愿顺序倒挂、相邻位次空档、重复院校、未标记项、选科不符（红牌）、计划缩招（≥20% 预警）、新招专业提示。

### 位次分级口径（已放宽）

投档位次 / 我的位次 ≤ 0.65 不建议；0.65–0.95 冲；0.95–1.15 稳；>1.15 保。80 个志愿位次充裕、大小年波动常见（高分段数百名、中分段数千名），因此不再把 0.85 以下一律判为不建议——1741 名对 1300 位次的专业会正确标为「冲」。

### 院校名称与校区

- 独立招生的分校/校区保留括号全名：哈尔滨工业大学（深圳）、华北电力大学（保定）、中国地质大学（武汉）、合肥工业大学（宣城校区）等；仅剥离「双一流/民办/2011计划」等标签括号
- 专业行显示「城市 · 校区」，校区从招生计划「专业简注」自动解析（兼容 `鼓楼+苏州校区`、`第一学年在朝晖校区，第二学年起在莫干山校区` 等写法）

### 等位分换算（实验性）

个人中心「实验性功能」开启后：方案表 2025 列下方显示「等位≈2026分」、查询行详情显示 25 等位分，并出现等位分换算器（任意 2023–2025 分数 → 2026 等效分，按一分一段位次映射）。为社区口径，仅供定位参考。

### 背景壁纸

个人中心「外观 → 背景壁纸」可选 8 张必应每日壁纸（本地离线）或自定义本地图片，开启后配合毛玻璃呈现沉浸式背景；无壁纸时保持纯色界面。

### 在线内容（院校图片与简介线上化）

个人中心「外观 → 在线内容」可切换自动 / 仅离线：

- **院校图片线上化**：校徽与校园图按需从掌上高考 CDN 在线加载（`<img>` 直连，不受 CORS 限制），失败自动回退到本地照片 / 程序封面；12 所名校本地照片保留作离线兜底
- **院校简介**：Top 319 所院校简介已预抓本地化（掌上高考院校库，含校训/官网/学科规模/QS）；其余院校通过本地代理在线获取并缓存
- **专业简介**：965 个本科专业目录（门类、代码、简介、主要课程、就业方向、薪资、热门行业）已全量预抓本地化；招生计划口径的课程/就业作为补充，「专业简注」降级为招生备注，不再冒充简介

### 推荐启动方式

双击 **启动.command**（macOS）：自动启动本地服务器（Python 3）并以在线模式打开，长尾院校简介走同源代理、带 30 天缓存。直接双击 `index.html` 也能使用全部本地功能，只是未预抓的院校简介不可在线获取（图片与专业内容不受影响）。

### 院校风景图

院校照片**在线优先加载**（直链保真，保证质量），加载失败自动回退本地缓存，再回退「矢量校徽 + 校色渐变」品牌封面；「在线内容」设为「仅离线」时直接用本地图。照片由用户终审定稿（162 所，来源为各院校官网/图集/自定义直链）。

## 录取模拟逻辑（与原工具一致）

1. 解析志愿表，提取每条志愿的院校代码与专业代码；
2. 按所选年份的投档线建立 `(院校代码, 专业代码) → 最低位次` 映射；
3. 按志愿顺序逐条判断：`最低位次 ≥ 我的位次` 即达标，第一条达标的志愿即为模拟录取结果；
4. 全部未达标则判定为滑档。

测试样例（`tests/`）中，681 分 / 1741 名在第 3 志愿命中南京大学技术科学试验班（2026 投档最低位次 1882），与真实录取结果一致。
