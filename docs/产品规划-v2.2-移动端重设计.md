# 产品规划 v2.2 · 移动端原生重设计规格

> 版本：2026-08-18 · 设计规划稿（先定设计、后写码）
> 上位文档：[产品规划-v2.2](产品规划-v2.2.md)（边界与验收）→ [执行方案](产品规划-v2.2-执行方案.md)（改动点编号 P-）
> 本规格回答"手机上每个页面长什么样、怎么操作"，不做桌面适配。

## 0. 原则：为什么不能照搬网页端

网页端是**宽屏 + 鼠标 + 多窗口**的产物：多列表格、悬停菜单、拖拽排序、小字号高密度、点击弹层。手机是**窄屏 + 拇指 + 单手 + 弱网**的产物。照搬的必然结果就是现在的问题：横滑表、找按钮、点不准、加载慢。

因此手机端每个页面都按以下顺序重新设计：

1. **先定义用户此刻要做什么**（核心任务），再决定界面；
2. **内容纵向流动**，不横向拖；
3. **主操作放拇指区**（屏幕下半部），次操作收抽屉；
4. **详情与编辑全屏化**，弹层只做轻确认；
5. **一次只给一个选择**，不用桌面式"全摆出来"。

## 1. 手机产品设计基线

### 1.1 拇指热区

- 主操作（添加/保存/查询/继续）永远在屏幕**下半区**，固定底部操作栏或 FAB。
- 危险操作（删除/清空/重置）置底、红色、二次确认。
- 高频次操作（收藏/加入方案）在卡片底部右侧，单手可达。
- 顶部只放"返回/标题/切换"，不放关键操作。

### 1.2 手势词典（新增/保留/移除）

| 手势 | 用途 | 说明 |
| --- | --- | --- |
| 点按卡片 | 打开详情全屏页/抽屉 | 全模块统一 |
| 卡片左滑 | 快速操作（志愿表=回收；查询=收藏/加入） | 滑动带操作按钮露出 |
| 卡片右滑 | 志愿表=快速改标记 | 或不做，保持简单 |
| 长按 | 进入排序模式（志愿表） | 有触觉反馈 + 抓取动效 |
| 上移/下移按钮 | 排序（保守方案，永不过时） | 与长按并存 |
| 双击 | 移除 | 手机不需要 |
| 桌面拖拽 | 移除（仅桌面保留） | 手机用按钮/排序模式 |
| 边缘右滑 | 全屏页返回（iOS 手势） | 顶部返回钮并存 |

### 1.3 桌面→手机组件映射（禁止照搬清单）

| 桌面组件 | 手机形态 | 备注 |
| --- | --- | --- |
| data-table 表格 | 卡片/列表 + 详情页 | 全站消灭手机横滑表 |
| 居中 modal | 底部抽屉 / 全屏页 | 轻确认才用弹窗 |
| 侧栏导航 | 底部 Tab + 底部抽屉 | 见执行方案 P-301~305 |
| 顶部胶囊切换 | 抽屉选择 / 芯片行 | 平板保留胶囊 |
| 拖拽排序 | 上移/下移/排序模式 | 见 §3.3 |
| 多列表单（label+ctl 栅格） | 单列大字段表单 | 输入 48px |
| 弹层内表格 | 详情列表 | 逐行展示 |
| 悬停反馈 | 按压态 | 不用 hover 替代 |
| 迷你图/图表 | 保留但放大 | 高度 ≥40px，可点大图 |
| 分享长图 | 保留，手机规格 | 390px 基准 |

### 1.4 视觉规格

| 项 | 值 |
| --- | --- |
| 间距基准 | 8px 网格；页面边距 16px；卡片内边距 14px |
| 圆角 | 卡片 14px；抽屉 18px（顶部）；按钮 10px；芯片 999px |
| 卡片阴影 | `0 1px 3px rgba(0,0,0,.08), 0 6px 16px rgba(0,0,0,.05)`；毛玻璃档加深 |
| 字号阶梯 | 页面标题 18 / 卡片标题 16 / 正文 14 / 数据 12 / 徽章 11（px） |
| 操作栏高度 | 底部操作栏 64px + 安全区 |
| 行高 | 列表行 52–56px；设置行 52px |
| 色彩语义 | 冲稳保垫选备 沿用 6 色；危险红、警示黄、成功绿固定语义 |

## 2. 手机组件系统规格

### 2.1 底部导航（Tab Bar）

- 5 个 Tab：工作台 / 志愿表 / 探索 / 认知 / 我的；图标 24px + 标签 11px。
- 高度 56px + 底部安全区；活动态主题色 + 顶部 3px 指示条。
- 志愿表 Tab 带数量角标（已填数/80）。

### 2.2 顶栏

- 高 48px + 顶部安全区；左：返回（二级页）或页面标题（一级页）；右：至多 1 个操作 + "⋯"。
- 一级页右角只有主题切换；智问移入"我的"（P-304）。

### 2.3 底部操作栏（关键新组件）

- 固定于 Tab Bar 上方，64px + 底部安全区，毛玻璃。
- 只放 2 个元素：主操作（大按钮，占 60%）+ 次操作（"⋯"）。
- 志愿表：`[＋ 添加志愿] [⋯]`；查询：`[查询/加载更多]` 视状态。

### 2.4 底部抽屉（Sheet）

- 圆角 18px 顶部、拖拽把手、标题栏（标题 + 关闭）、内容滚动、最大高 85vh。
- 打开时锁背景滚动、遮罩点击关闭、0.22s 上滑动效。
- 键盘场景用 `visualViewport` 避让。

### 2.5 全屏二级页

- 右滑进入 + 顶栏（返回/标题/操作）；内容区独立滚动。
- 用于：卡片详情、编辑表单、阅读、体检、回收站、筛选结果详情等。

### 2.6 芯片（Chip）行

- 筛选/标记/分类统一用横滑芯片行：高 40px、圆角 999px、可多选、选中主题色填充、带计数徽章。

### 2.7 空态与骨架

- 空态 = 图标 + 一句话 + 一个主操作按钮（≥48px）。
- 加载 = 骨架卡（呼吸动画，reduced-motion 静态）。

## 3. 深度重设计 · 志愿表

### 3.1 设计判断

志愿表的产品本质：**维护一个有序的 80 项列表，并不断评估它的质量**。手机上它不需要是"表"，而是"可排序、可筛选、可体检的列表"。

三个使用模式：

1. **浏览/筛选模式**（默认）：看整体、按标记筛选、改标记。
2. **排序模式**：调整顺序（核心任务，单独模式保证专注）。
3. **详情模式**：看一项的六年数据与全部信息。

## 4. 深度重设计 · 个人中心

### 4.1 设计判断

个人中心本质：**考生档案 + 数据管理 + 外观 + 工具**。手机上不是"设置列表"，而是"我的"——身份感 + 分组直达。v2.1 的"列表+二级面板"方向对，但面板内容仍是桌面表单（label 栅格、小按钮），分组也缺层级。
