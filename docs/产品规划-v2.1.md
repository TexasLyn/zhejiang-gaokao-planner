# 潮汐志愿 2.1 · 产品规划

> 2026-08 · 在 2.0「决策工作台」之上的本周期规划
> 一句话：2.0 把工具做全了，2.1 要把「判断」做厚——从「能查到」到「能读进去、用得上」。

## 0. 周期定位

| 版本 | 定位 | 核心承诺 |
| --- | --- | --- |
| 1.x | 本地志愿管理工具 | 数据全、填得下 |
| 2.0 | 浙江考生决策工作台 | 填得对、填得明白 |
| **2.1（本周期）** | **白皮书馆 · 内容决策一体化** | **每个关键决策都有出处、有观点、能讲清** |
| 3.0 | 浙江升学决策平台 | 浙江考生的每一种升学路径、每一所院校都有深挖 |
| 4.0 | 浙江生涯数字伴侣 | 从选科到就业，每一步都有依据（始终限浙江） |

> **边界声明：永远做浙江产品。** 不做外省、不复制省份、不摊大饼；所有数据、内容、决策逻辑只服务浙江考生，把浙江的深度做成护城河。

## 6. 北极星与指标

- 建档 → 体检全绿 ≤ 30 分钟。
- 白皮书阅读完成率、读后"改变过至少一个志愿决策"占比。
- 认知板块停留时长与二次访问率。
- 数据准确率：零已知错误（发现即修 + 版本日志记录）。

## 7. 风险与边界

- 内容主观性：白皮书观点必须标注来源、时效与"仅供参考"。
- 脱敏红线：群聊素材不得出现群名、实录、匿名整理痕迹。
- 数据维护：依赖年度官方文件，需建立更新 SOP。
- 免费托管限制：本地优先、静态部署、控制单文件体积。
- 不做外省：拒绝多省化诱惑，避免数据口径不一致与维护失焦；增长靠浙江纵深，不靠省份复制。
