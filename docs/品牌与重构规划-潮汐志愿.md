## 一、品牌：潮汐志愿

### 定名

- 中文名：**潮汐志愿**（替换「浙志愿」）
- 英文标识：**TIDE**（全称 Tide Zhiyuan / Tidal Choice 备用）
- 气质关键词：潮汐、刻度、落点、涨落、笃定
- Logo：**暂不动**，后续沿「潮线 + 刻度」方向设计，不做强制更换

### Slogan（已定）

**顺潮而行，落笔有光**

（备选存档：潮汐有信，志愿有痕 / 涨落之间，自有方向 / 潮水会退，落笔无悔 / 此岸到彼岸，只差一个落点）

### 视觉气质

- 主色：潮汐蓝（深蓝→青蓝渐变）+ 月白
- 隐喻系统：潮线 = 位次曲线；潮位 = 冲/稳/保梯度；刻度 = 数据
- 文案语气：克制、有诗意，减少「工具/产品」字眼，多用「潮、岸、落点、刻度」

   - 点击进入整本阅读；未读/已读进度各自独立
2. **统一阅读器**（复用现有认知阅读器能力，扩展）：
   - 吸顶目录胶囊、阅读进度条、上一章/下一章、字号/明暗（现有能力）
   - 新增：三本主题色各自生效；封面信息区（写给谁/数据口径/阅读路径）
3. **结构化数据**：
   - 数据文件：`data/whitepaper-cognition.js`（现有重命名/保留）、`whitepaper-arts.js`、`whitepaper-cs.js`
   - 生成脚本：扩展 `tools/gen-whitepaper.py`，把 docs 两本 Markdown 转成与认知同构的 JSON（章节树 + 表格 + 引用 + 链接 + 术语表）

4. **节选联动**（三本共用一套机制）：
   - 专业详情/专业认知弹窗按「专业名 + 人群」匹配对应白皮书的节选卡

   - 文科白皮书的人文专业/院校段落 → 专业与院校详情节选
5. **其他**：
   - 阅读器内保留「去专业探索看看」等现有闭环
   - 三本白皮书之间可互相跳转（书尾「下一本」引导，按选科人群推荐）

### 实施顺序

1. 生成脚本扩展：解析两本 Markdown → 结构化 JSON（先保证章节与正文完整，再补术语/表格）

## 四·补充：城市认知板块修复 + 探索联动

### Bug 现状

城市认知板块中，院校专业、排名等数据为空。

### 修复方案

1. **补数据**：城市认知按城市聚合现有数据源——
   - 院校：`GK_SCHOOLS.meta`（排名 rk/软科）、`GK_RANKS`（软科主榜/世界榜/学科榜命中）
   - 专业：`GK_MAJOR_DB`（该城高校的王牌/特色专业）
   - 投档：`GK_LINES["2026"]` / `GK_LIBRARY_2026`（该城院校 2026 计划与最低位次）
   - 城市字段来自计划库 PROV/CITY（现有）
2. **「详细认知」按钮**：城市认知每所院校卡片新增按钮 → 打开**探索板块对应院校详情页**（复用现有院校详情弹层/页面），实现两处定位互补：
   - 城市认知 = 宏观（这个城市有什么、产业与学校的关系）
   - 探索院校详情 = 微观（这所学校具体数据、专业、排名）
3. 联动入口同时反向补充：院校详情页若命中城市认知，展示「看看这座城」入口
