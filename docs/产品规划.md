# 产品规划 · 完整系统头脑风暴

> 设计师视角：以「决策质量」为核心，功能分层演进；所有新增界面延续当前视觉语言（中性底色、单一主色、语义色分层、克制动效），不引入"AI 生成感"的装饰。

## 一、分层蓝图

### L1 数据层（当前已完成）

- 官方投档线 2023–2026 + 一分一段 + 计划库（选科/学费/学制）✓
- 后续：接入 2021–2022 补齐五年；多省份模板；每年发布后一键更新数据包

### L2 决策层（下一步重点）

1. **等位分换算**：把历年分数统一换算成 2026 等效分（按一分一段位次对应），表格里直接对比「今年等效」而非原始分数。
2. **波动视图**：每条志愿展示近四年位次折线 + 波动区间，一眼看出冷热趋势；波动大的标注「大小年」。
3. **梯度体检**：对方案整体诊断——冲/稳/保比例、相邻志愿位次差、重复院校占比、80 个空位分配建议；给出「建议把第 N 志愿前移」类提示。
4. **选科体检**：逐条校验方案内志愿的选科要求是否满足，不满足直接标红（2024 年起理工农医基本绑死物化）。
5. **同分同分位次说明**：解释「分数相同看位次」的投档规则，模拟录取时用位次而非分数判定。
6. **计划数变化提示**：今年计划数 vs 去年计划数的增减，缩招专业提示风险。
7. **新增专业/院校标记**：今年首次招生、改名院校、新增校区的识别。

### L3 协作层

8. **方案分享**：一键生成只读链接或图片长图，给家长/老师审阅；带敏感信息脱敏选项。
9. **多角色协同**：考生方案 + 家长备注层 + 老师批注层，互不覆盖。
10. **时间轴**：志愿填报关键节点（出分、一段填报、二段填报）倒计时与待办清单。

### L4 发布层

11. **官方导入表导出**：按浙江省高校招生考试信息管理系统要求的「志愿导入表.xls」格式导出，含选科/英语/限报核对清单。
12. **PDF 报告**：方案总览、梯度分析、模拟录取结果一键导出 PDF（含免责声明）。
13. **云备份**：WebDAV / 网盘自动备份，本地数据不丢（当前仅本地存储）。

## 二、体验细节（设计向）

- 表格「冻结首列 + 横向微缩」，80 个志愿在窄屏也能顺畅拖拽；
- 拖拽排序支持触屏（长按进入拖拽 + 震动反馈）；
- 统计面板升级为「方案健康分」：梯度合理度、选科通过率、重复率三个指标用仪表形式呈现；
- 一分一段山峰图增加年份叠加对比（把 4 年曲线叠在一张图上，透明度分层），看分数段竞争趋势；
- 暗色模式统一语义色亮度，保证色盲可辨（冲/稳/保同时用形状辅助，不只靠颜色）；
- 键盘流：数字键直接切换标记，Enter 确认排序，全程可脱离鼠标；
- 空状态用真实文案（如「还没有志愿，先去数据查询找找」），不放装饰插画。

## 三、优先级建议

**P0（决策刚需）**：等位分换算、梯度体检、选科体检、计划数变化提示
**P1（效率）**：波动视图、官方导入表导出、方案长图分享
**P2（完整系统）**：云备份、PDF 报告、多角色协同、时间轴、多省份

## 四、不做的事

- 不做「预测录取概率」类伪精确数值——投档是位次博弈，给出区间与依据比给百分比更负责任；
- 不接入任何需要登录的第三方服务，保持「打开即用、数据在我手里」的定位。
