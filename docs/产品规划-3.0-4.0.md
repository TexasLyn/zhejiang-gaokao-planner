# 浙志愿 3.0 / 4.0 · 未来展望

> 设计师视角 · 2026-08 · 在 2.0「决策工作台」基础上的演进蓝图
>
> 主线叙事：**工具 → 平台 → 生态**
> 2.0 让一个人把 80 个志愿填明白；3.0 让一个省甚至多个省的考生共享决策能力；4.0 让每个人从选科到就业的每一步都有陪伴与依据。

## 0. 一句话定位（各版本）

| 版本 | 定位 | 核心承诺 |
| --- | --- | --- |
| 1.x | 本地志愿管理工具 | 数据全、填得下 |
| 2.0 | 浙江考生决策工作台 | 填得对、填得明白 |
| 3.0 | 多省升学决策云平台 | 一个省复制到更多省，一家人一起决策 |
| 4.0 | 生涯数字伴侣 | 从选科到就业，每一步都有依据 |

## 1. 三版本主线（贯穿演进）

### 1.1 数据资产线

- 2.0：数据版本化、年度更新包、数据字典
- 3.0：多省数据接入（投档线 / 一分一段 / 选科要求 / 计划），统一规则层
- 4.0：开放数据 API、匿名贡献回馈（录取结果回流改善模型）、15 年长周期数据

### 1.2 决策引擎线

- 2.0：概率区间、风险地图、策略助手、快照对比（规则驱动）
- 3.0：多省规则包 + 方案引擎抽象；历史数据更长、概率模型更稳
- 4.0：AI 生涯顾问，长期记忆 + 模拟推演，端侧小模型 + 云端大模型

### 1.3 信任线（永远不变）

- 所有结论给依据、可回溯（哪个文件、哪一年、哪个位次）
- AI 输出一律标注「仅供参考」
- 不承诺录取、不贩卖焦虑、不卖数据

## 2. 3.0 · 从工具到平台

> 主题：**协同 · 多省 · 全链路 · AI 深度**

### 2.1 账号与云（可选，仍本地优先）

- 账号体系可无：默认继续「打开即用、数据在我手里」
- 可选云同步：多设备实时同步（自有服务 / WebDAV / 网盘）
- 数据保险箱：自动版本化备份、一键恢复、一键导出/彻底删除
- 隐私模式：完全离线可用，云端数据可随时撤回

### 2.2 多省模板（横向扩展）

- 志愿规则引擎：抽象「填报规则包」（浙江 80 平行志愿、一段二段；山东/河北 96 个；江苏 40 院校专业组……）
- 数据接入：各省考试院投档线、一分一段、选科要求、招生计划
- 同套决策引擎复用：探索 / 概率区间 / 风险地图 / 策略助手全部跨省
- 浙江保持最深：政策、数据、案例持续领先，作为「样板省」

### 2.3 全升学链路（纵向扩展）

- 高一高二：选科决策（专业限科反查、兴趣测评、选科博弈分析）
- 高三：强基 / 三位一体 / 综合评价管理（报名日程、材料清单、校测准备）
- 提前批 / 公安 / 军校 / 艺术体育 / 定向：专项模块
- 录取后：入学准备（行李、宿舍、军训、转专业政策）、大一规划
- 深造衔接：推免率、保研路径、考研数据（已有数据基础延伸）

### 2.4 协同层（家庭 + 老师）

- 多角色：考生 / 家长 / 老师，权限分层，互不覆盖
- 方案审阅流：提交 → 老师点评 → 修订记录（2.0 快照对比的延伸）
- 云同步下的实时协作：多人看同一份方案，批注即时可见

### 2.5 社区与知识（UGC）

- 院校口碑：在读学生认证发言（食堂 / 宿舍 / 学习氛围 / 转专业难度）
- 专业避坑指南：学长学姐真实经验结构化挂载
- 录取报喜墙：脱敏晒录取，真实案例库（你的「681 → 南大技科班」是第一个）
- 问答社区：政策问答，AI 初审 + 人工复核

### 2.6 AI 深度（智问 2.0）

- 规则 + 大模型混合：答案带数据依据（引用具体年份位次与来源）
- 方案口语化解读：「你的方案问题在于兜底偏紧，第 12 志愿和 9 志愿重复度过高」
- 个性化推荐：基于收藏/浏览的可解释推荐（为什么推荐、依据是什么）
- 语音查询：说话查数据（「浙大计算机去年多少分」）

### 2.7 平台技术

- PWA 原生化：离线、日程推送
- 桌面端（Tauri）与移动 App（可选）
- 数据开放：标准导出格式（JSON / CSV / Excel），未来 API
- 性能：万级数据秒开、增量渲染

## 3. 4.0 · 从平台到生态

> 主题：**生涯全景 · AI 顾问 · 开放生态 · 教育公平**

### 3.1 生涯全景（全生命周期）

- 从高一选科到大学毕业就业/考研的完整时间线
- 个人生涯档案：选科、成绩、志愿、录取、专业、绩点、实习、就业——一生可查
- 阶段衔接：高考 → 转专业 → 保研 → 考研 → 就业 / 考公，每一步都有数据支撑

### 3.2 AI 生涯顾问（4.0 核心）

- 长期记忆：了解兴趣、能力、性格、家庭背景
- 对话式生涯规划：「我适合学医吗？」给出数据 + 真实访谈 + 决策框架
- 模拟推演：「如果选了 XX 专业，5 年后可能怎样」（基于真实毕业生数据）
- 多模态输出：语音、卡片、短视频解读

### 3.3 开放生态

- 开放 API：数据服务、院校库、专业库接口
- 第三方接入：高校招生办、公益组织、内容共建机构（严格审核）
- 插件 / 模板市场：各省规则包、专题内容（「警校专题」「医学专题」）
- 数据贡献机制：匿名化用户数据回馈，录取结果回流改善模型

### 3.4 教育公平

- 核心永久免费；公益专项：贫困地区数据免费、志愿者结对
- 乡村考生版：极简模式、低流量、离线包
- 无障碍：色盲 / 低视力 / 键盘流（2.0 已埋基础）

### 3.5 沉浸与信任

- 校园数字导览（VR / 全景图，可选、有节制）
- 数据可信度标签：来源、年份、核实状态，一眼可辨
- 政策变化实时监测：AI 自动更新日程与规则

### 3.6 商业与可持续

- 核心免费；增值：高级分析报告、专家咨询市场（第三方、严格准入）
- 赞助升级为「支持者」体系（现有收款码的延伸）
- 合规：未成年人数据保护、匿名化、可删除权

### 3.7 技术展望

- 端侧 AI（本地小模型跑规则） + 云端大模型增强
- 跨端实时同步
- 长期数据积累 → 概率模型每一年更准

## 4. 里程碑与节奏建议

| 阶段 | 主线 | 验收标准 |
| --- | --- | --- |
| 2.0 α→GA | 决策引擎 + 设计系统 + 认知层 | 30 分钟产出体检全绿方案 |
| 3.0 α | 多省规则层 + 云同步（可选） | 第二个省份完整跑通 |
| 3.0 β | 全链路 + 协同 + 社区 + 智问 2.0 | 一个家庭完成一次完整填报闭环 |
| 4.0 α | 生涯档案 + AI 顾问 | 用户升学后继续使用率 > 50% |
| 4.0 β | 开放 API + 公益专项 + 生态 | 有第三方开发者接入 |

## 5. 一直不做的事（原则红线）

- 不做「保证录取」类承诺
- 不卖考生数据
- 不把 AI 当权威（永远给依据）
- 不为了商业化破坏公益属性
- 不堆功能：每个版本只回答一个核心问题

## 6. 需要拍板的决策点

1. **3.0 是否上账号 / 云**：继续纯本地 + 手动同步（推荐先做 WebDAV 自动备份），还是上自有账号体系？
2. **多省节奏**：先把浙江做成「极致样板」，还是尽早横向复制？
3. **社区 UGC 的审核成本**：实名/认证门槛多高？
4. **商业化程度**：纯公益 / 增值服务 / 开放广告位（不推荐）？
5. **4.0 的 AI 依赖**：端侧优先还是云端优先？
