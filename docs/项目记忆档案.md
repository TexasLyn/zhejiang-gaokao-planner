## 附：恢复方法（如需重做）

会话记录在 `~/.codex/sessions/2026/08/*/rollout-*.jsonl`，每个文件是 JSONL：

- `session_meta` → 线程 id、session_id（主线程）、cwd、是否子会话
- `event_msg` 的 `user_message` / `agent_message` / `task_complete` → 对话内容
- `compacted` → 长对话的自动摘要（蹭饭图等长线程里有）
- `~/.codex/session_index.jsonl` → 线程名索引

提取示例：

```bash
jq -r 'select(.type=="event_msg" and .payload.type=="user_message") | .payload.message' <文件>
jq -r 'select(.type=="event_msg" and .payload.type=="agent_message") | .payload.message' <文件>
```
