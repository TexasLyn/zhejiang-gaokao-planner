# 潮汐志愿 2.2 · 产品规划

> 2026-08 · 体验纯享版
> 主题名：**「掌上潮汐」**
> 一句话：这一版不新增任何功能，只做一件事——让潮汐志愿在每一块屏幕上（手机 / 平板 / 折叠屏 / 小屏 / 横屏）都像原生应用一样舒服。

## 1. 为什么叫「掌上潮汐」

潮汐的核心使用场景正在从桌面转向手机：考生在地铁上、课间、饭桌上翻方案。2.2 把"能用"升级为"好用"——信息密度、触控尺寸、动效节奏都按手机重新设计，同时保证桌面端体验不回退。

## 2. 范围与边界（严格）

**本周期只允许两类改动：**
1. 显示效果（布局、尺寸、间距、字号、颜色、动效、安全区）。
2. 交互容器（把桌面交互改造成适合触控的形式，如拖拽→上移/下移按钮、列表→二级面板）。

**禁止：**
- 新增功能/数据/入口/设置项。
- 改变信息架构（仍为 工作台/志愿表/探索/认知/我的 五个一级入口）。
- 改变桌面端现有视觉语言（桌面只修 bug，不做重设计）。

## 3. 迭代计划

### 3.1 移动端（≤720px）
- 个人中心：列表 + 二级全屏面板（已完成首版，继续打磨层级与返回动效）。
- 志愿表：表格 → 卡片流（已完成首版），继续优化字段胶囊密度、操作栏触控区。
- 底部 Tab 栏、探索二级导航、弹层/底部抽屉：统一安全区与毛玻璃规范。
- 触控目标 ≥ 40px；去掉双击缩放与点按高亮闪烁。

### 3.2 不同比例屏幕（本周期重点新增）
- **小屏 320–374px**：字体阶梯、卡片间距、按钮文字压缩规则。
- **常规手机 375–430px**：基准设计宽度，验收主场景。
- **平板 720–1080px**：侧边栏收窄、双列布局接管、避免"放大版手机"。
- **折叠屏 / 窄分屏（~360px）**：短边适配，横竖屏切换不丢状态。
- **横屏手机**：高度受限时的滚动与工具栏策略。
- **刘海屏/全面屏**：顶部与底部安全区（env(safe-area-inset-*)）全覆盖。

### 3.3 通用体验
- 动效：统一 0.12–0.28s 缓动曲线；弱网/低性能设备自动降级（prefers-reduced-motion）。
- 滚动：iOS 惯性滚动、滚动条隐藏、吸顶元素不遮挡内容。
- 可读性：所有界面在浅色/深色/毛玻璃三种状态下的对比度校验。

## 4. 验收指标

- 320 / 375 / 390 / 430 / 768 / 1024 六档宽度逐页检测：无横向溢出、无内容截断。
- 移动端所有可点元素触控区 ≥ 40×40px。
- 桌面端回归：5 个一级页 + 认知子板块截图对比，无回退。
- 零功能变更：版本日志 2.2 段不出现任何新功能条目。
