## 二、数据补强队列

### P0（最影响专业性，先做）

1. **就业·全景精细数据**：按专业 × 院校 × 层次补全薪资、去向、深造率。来源：各校就业质量年度报告、麦可思蓝皮书分专业数据、公开招聘报告。**这是用户多次点名「数据狠狠爬」的板块。**
2. **城市产业介绍全量化**：322 城中把 65 城精编扩展到全量（每城：城市是什么 / 产业构成 / 高校 / 与大学的关系 / 就业半径 / 适合谁）。

## 四、工作规范

- 每个数据文件头注释：**来源、年份、口径、是否「仅供参考」**。
- 网传数据一律标注「仅供参考」，重要结论用官方/权威媒体交叉验证。
- 新数据先落 data-src/ 或 docs/，**确认后再产品化**，不在本阶段动 index.html。
- 素材归档按主题分子目录：data-src/学科评估/、就业/、城市/、院校/、政策/、分析底稿/。
